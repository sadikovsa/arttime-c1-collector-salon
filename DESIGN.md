## 2. Визуальная система

Винная типографическая плоскость занимает42% desktop hero; стеклянная композиция справа. Крупный настоящий курсив Cormorant Garamond300–700, интерфейс Manrope200–800, локальные шрифты и OFL. Нижние главы — тёплая бумага, светлый камень, тёмный текст. Контент до1200px, fluid gutter22–72px, fullbleed только hero. Заголовок expansive, три строки desktop. Единый muted token`#655c51` в`dist/assets/css/tokens.css`: тёмный тёплый stone оттенок длявторичного текста, контраст наstone`#e4dccf` ≈4.82:1 (AA длямалого текста). Первоначальный`#6e6559` скорректирован после10узлов color-contrast вroot axeQA. Никаких подчёркиваний ссылок. Прямоугольные спокойные CTA, тонкие разделители секций, без общей сетки плавающих карточек и декоративных маркеров источников.

Последовательность: предметная сцена → две редакционные фотоподборки → полная витрина16предметов →5реальных групп наполнения → отдельно2интерьерные идеи →3иллюстрированные услуги →FAQ с фото →локальный запрос и оригинальные контакты →компактный адресный футер.

## 3. Движение

Движок: собственный native scroll + sticky + requestAnimationFrame, без GSAP/ScrollTrigger. Не заявляется 3D или реальный пролёт сквозь стекло.

Desktop сцена210svh, sticky кадр100svh. Дополнительный диапазон110svh.0%: винная плоскость42%, фотография translateX18% и scale1.04, полный заголовок иCTA.50%: плоскость уменьшается scaleX0.5, фотография translateX9%/scale1.02; заголовок уходит вверх и исчезает.100%: винная плоскость scaleX0, одно фото fullframe translateX0/scale1. Следующая глава — фотоподборка, без дублирующего полного экрана той же сцены. Скролл назад вычисляет те же состояния; колёсико не перехватывается.

Mobile: кадр над текстом, сцена135svh со sticky100svh, ограниченный scale1→1.07 фотографии. Текст иCTA остаются читаемыми, без исчезновения. Pause сохраняет текущий кадр, диапазон иscroll position; resume возвращается к текущему реальному прогрессу. Reduced motion/noJS — статичный hero в нормальном потоке. Меню и details раскрываются270ms; только раскрывающимся панелям разрешено height. Остальное движение transform/opacity.

## 4. Доступное поведение

16предметов присутствуют в HTML. NoJS: все категории видны, native details раскрывает исходное описание и спецификацию; телефон доступен. Галерея открывает исходные фото обычной ссылкой. Навигация доступна безJS.

Enhancement: категории с aria-pressed, поиск без изменения во время IME composition, мгновенная очистка, пустое состояние с восстановлением коллекции; URL category/q. Native dialog предмета содержит original photo/описание/спецификацию/цену по запросу; Escape, inert background, close, bounded scroll, возврат фокуса. Native viewer изолирует5case и2inspiration группы, next/prev и стрелки клавиатуры. Услуги и FAQ — native details с обратимой270ms WAAPI-анимацией. Меню mobile имеет44px controls, aria-expanded, inert в закрытом состоянии, Escape/restore.

## 5. Запрос

Форма не отправляет сеть. Имя/контакт валидируются с aria-invalid/error text/first invalid focus. Предмет и сообщение необязательны, объект из диалога заполняется автоматически. Подготовленный текст редактируется в отдельном textarea. Копирование использует текущий текст; при недоступном Clipboard API текст выделяется с инструкцией. TXT UTF-8/BOM формируется из актуальной правки. Контакты не хранятся в cookies/localStorage. Оригинальные телефон, Instagram и адрес всегда видимы. Публичной ложной отправки/ожидания ответа нет.
